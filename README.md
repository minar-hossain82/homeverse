# 🏠 Homeverse – Real Estate Landing Page

Homeverse is a modern and responsive real estate landing page designed to showcase properties, real estate services, featured listings, and housing solutions. The website focuses on delivering a clean and engaging user experience with a responsive layout, modern UI, and intuitive navigation.

## 🌐 Live Demo

🔗 https://minar-homeverse.vercel.app/

## 📂 GitHub Repository

🔗 https://github.com/minar-hossain82/homeverse

## ✨ Features

* 🏠 Modern real estate landing page
* 📱 Fully responsive design
* 🔍 Property search interface
* 🏡 Featured property listings
* 💰 Property pricing and details
* 🏢 Real estate services showcase
* 📍 Property location information
* 📸 Property image gallery
* 📝 Real estate blog section
* 📞 Contact section
* 📱 Mobile-friendly navigation
* ⬆️ Back-to-top button
* ⚡ Smooth user experience

```bash

```

Simply open **index.html** in your browser.

Or use **VS Code Live Server**.
